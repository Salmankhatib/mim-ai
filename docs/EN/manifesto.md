# MIM Manifesto

## Why this project exists

Moroccan developers need practical AI tooling that understands the realities of Darija, code-switching, local regulatory expectations, and real deployment constraints.

MIM is built to reduce the friction between model access and shipping working features.

## Principles

- Darija-first, not English-first
- config over code
- provider-agnostic integration
- auditability by default
- low-friction developer experience

## Alignment with national strategy

MIM supports the broader goal of building local AI capability, reusable technical foundations, and deployment-ready products in Morocco.

## The mission

To give developers a lightweight toolkit that helps them ship Arabic-script, Arabizi-aware, voice-ready AI products without reinventing the stack every time.
